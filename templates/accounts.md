# Accounts — external services on record

**Accounts are shared, credentials are not.** One founder login per
provider; each venture provisions its own resources inside it (project,
workspace and API key, buckets, domains, `.env`). Nothing is copied from
another venture's `.env`.

Nothing recorded yet. Venture agents read this before asking the founder
for any account, key, or spend. List each external service that exists,
the date the founder confirmed its status, where its credentials live (a
path or variable name — never a value), and standing spend approvals.
A row without a founder-confirmed date is a report, not a fact.
`example/accounts.md` shows the filled-in shape.
